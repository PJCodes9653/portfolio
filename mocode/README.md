# 📡 MoCode - Morse Code Translator

**MoCode** is a sleek, modern, and interactive web application designed to seamlessly translate English text into Morse code and vice versa in real-time.

[⚡ Live Demo](https://pratham-jain33.github.io/MoCode/)

---

## ✨ Features

- ⚡ **Instant Auto-Translation**: Translates text and Morse code dynamically on every keystroke without needing to press a translate button.
- 🔊 **Audio Playback & Controls**: Play synthesized Morse code audio dots (`.`) and dashes (`-`) directly in your browser with interactive play/stop toggle controls.
- 🟢 **Visual Signal Flasher**: Synchronized visual light indicator that pulses along with audio playback.
- 📖 **Morse Code Cheat Sheet**: Built-in interactive popup guide displaying letters, numbers, and symbols alongside their Morse code translations.
- 📋 **One-Click Copy & Reverse**: Easily copy translation results or reverse input/output text with a single click.
- 📜 **Translation History**: Automatically logs your recent translations locally.
- 📱 **Fully Responsive & Glassmorphism Design**: High-performance UI tailored for both desktop and mobile screens.

---

## 🚀 How It Works

1. **Text to Morse**: Type standard text into the input area. MoCode automatically detects text input and translates each letter and number into Morse code separated by spaces and `/` for word gaps.
2. **Morse to Text**: Type or paste Morse code (`.` and `-`) into the input area. MoCode converts the symbols back into clear readable text automatically.
3. **Listen & Flash**: Click the volume button (`🔊`) to hear the Morse audio beep while observing the visual signal beacon light up in real-time.
